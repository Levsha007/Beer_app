## 5. Инструкция по обновлению

```bash
# 1. Остановить контейнеры и удалить старый том с БД
docker-compose down -v

# 2. Заменить файлы:
#    - init.sql (полностью)
#    - models.py (полностью)
#    - README.md (опционально)

# 3. Пересобрать и запустить
docker-compose up --build
```

После запуска база автоматически инициализируется через `init.sql` (смонтирован в `/docker-entrypoint-initdb.d/`). Вы увидите в логах статистику: 8 поставщиков, 18 продуктов, 7 характеристик, ~500-700 связей.

Готово! Система теперь работает с вариантом **Склад ГСМ**. 🛢️
